## Proposal (user)

`docs/next-session.md` §2-1의 후보 셋 중 하나를 판정한다.

- Tauri 2 + Vite + TS — 기존 위젯 3종과 같은 툴체인, 렌더러·에디터 생태계가 두텁고 설치본이 작다. Rust 빌드 체인, 파일 연결·감시는 Rust 플러그인
- WPF (.NET) — 순수 네이티브, 파일 API 자연스러움. 미리보기는 결국 WebView2 + Markdig
- WinUI 3 (.NET) — 최신 Fluent 룩. 도구·배포가 까다롭고 에디터 컴포넌트 부족

## Context

- Goal of this pass: 개인용 Windows 10/11 `.md` 뷰어·편집기. 더블클릭 → 1초 내 깔끔한 렌더, 파일 연결, 무편집 저장 시 바이트 불변, 한국어 입력·CP949
- Constraints: 사용자 PC Windows 10 Pro 19045(2025-10 지원 종료) + Windows 11 검증. 기존 프로젝트 관례(Tauri 2 / Vite 6 / TS 5.6, vanilla TS). 앱 코드는 이 판정이 `ADOPT*`로 기록된 뒤에만 작성 (`CLAUDE.md`)

(4) `dragDropEnabled`와 HTML5 DnD 양자택일(S8). (5) 무음 PDF는 COM 직접 호출(G20). (6) Rust 릴리스 빌드 시간(S19). (7) Windows 시작 시간·메모리 실측 자료 없음(S19) |

## Decision

- Verdict: `ADOPT_WITH_CHANGES` (승인 2026-09-29, 배치 승인 항목 1·5)
- What we will do now: `docs/roadmap.md` Phase 0 — `exp/ime-spike`에서 IME 스파이크, `mdeditor-core` 바이트 보존 코어, Tauri hello vs **WPF + WebView2 hello** 시작 시간·메모리 나란히 측정. CM6 plain이 IME 시나리오를 통과하면 조건 없는 `ADOPT`로 갱신하고 Phase 1 스캐폴딩
- What we will not do: WinUI 3·Avalonia·Flutter 검토 재개. MSI(WiX) 번들(perMachine 고정, '연결 프로그램' 미노출 — A12). 스파이크 통과 전 제품 스캐폴딩
- Modified approach (조건·변경점):
  1. **게이트**: Phase 0에서 `exp/ime-spike` 브랜치로 textarea / CM6 plain / CM6+데코레이션 세 구성을 한국어 MS IME(새/이전) × Win10 19045/Win11에서 실측. 기존 텍스트 첫 포커스(tauri #15436), 조합 중 포커스 이탈(#5475), Enter/Ctrl+S 이중 발화, 줄바꿈 경계, YAML 직후 문단 시나리오(G16–G18). **CM6 plain이 통과하면 ADOPT 확정**. 실패하면 (a) `additionalBrowserArgs`에 `--disable-features=…,TSFHonorAutocorrectOff`(G6), (b) textarea/EditContext 입력 모델(G7, SoloMD 4.7 방식), (c) 그래도 실패 시 Electron 폴백을 새 판정으로
  2. **런타임 핀**: tauri ≥ 2.12.0(tao ≥ 0.35.4, O8), `tauri-plugin-single-instance` ≥ 2.4.5(S3), WebView2 최소 버전 150 (`bundle.windows.nsis.minimumWebview2Version`, G3). `webviewInstallMode`는 `downloadBootstrapper` 유지(fixedRuntime은 회귀 비상 카드, G4)
  3. **파일 I/O는 Rust 커맨드 자작**: fs 플러그인의 `readTextFile`/`writeFile` 사용 금지. 원시 바이트 → BOM(`for_bom`) → UTF-8 검증 → chardetng(`Utf8Detection::Deny`, EUC-KR 후보) → 디코드. 저장은 무편집이면 원본 바이트 그대로, 편집 시 `encode_from_utf8_without_replacement`로 손실 검사 후 임시파일 + `ReplaceFileW` (S10·S11·F24·E15)
  4. **설치기**: NSIS `installMode: currentUser`, `fileAssociations name: "MdEditor.Markdown"`(벤더 접두, S1), `NSIS_HOOK_POSTINSTALL`에 `OpenWithProgids`·`Applications\<exe>\SupportedTypes`·`Capabilities`+`RegisteredApplications`·`UPDATEFILEASSOC`, `POSTUNINSTALL`은 자기 값만 제거(A8–A11·A14). 앱 내 "기본 앱으로 설정" 버튼은 `ms-settings:defaultapps?registeredAppUser=MdEditor`(A4), 현재 기본값 조회는 `QueryCurrentDefault`(A1·A3)
  5. **프론트**: vanilla TS + Vite(위젯 관례). `dragDropEnabled: true` 유지(파일 드롭 열기), 에디터 내부 드래그는 pointer 이벤트(S8). `on_navigation`으로 `file:`·상대 링크 가로채기(G15). 한글·공백·`[`·`#` 경로 픽스처(G14)
  6. **렌더 스택**: markdown-it 15 + `markdown-it-cjk-friendly` + anchor/task/footnote + DOMPurify + highlight.js core(후에 Shiki) + KaTeX/Mermaid 지연 로드 + github-markdown-css 기반 + 한국어 오버라이드(`:lang(ko)` keep-all, Pretendard, D2Coding 번들) (R1·R7·R13·R24·G22–G24)
  7. **PDF**: MVP는 HTML 내보내기 + `window.print()`. 무음 PDF·헤더/푸터는 후속 Phase에서 webview2-com COM 어댑터(meditor PR #188 패턴) 또는 CDP (G20·G21)
