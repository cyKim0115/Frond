- Idea id: `20261006-license`
- Status: `decided`
- Verdict: `ADOPT`
- Related: [`20261006-store-monetization.md`](20261006-store-monetization.md) · [`LICENSE`](../../../LICENSE) · [`TRADEMARKS.md`](../../../TRADEMARKS.md) · 조사 [Frond 스토어 유료 해금 방식](../../research/reports/Frond%20스토어%20유료%20해금%20방식.md) 결정 D4

## Proposal (user)

- 2026-10-06 "라이선스는 권하는대로" — 조사 보고서 권장안(MIT를 LICENSE 파일로 확정, 구매자 전용 테마도 저장소에 공개, 이름·아이콘만 따로 보유)을 그대로 채택

## Context

- 상태가 어정쩡했다: `README.md` 라이선스 절과 `Cargo.toml` `license = "MIT"`는 MIT라고 적었지만 LICENSE 파일이 없어 GitHub가 라이선스를 감지하지 못했다. 저장소는 공개
- 같은 날 Microsoft Store 배포 + 선택 구매(테마 해금)로 방향을 정했다 → 공개 저장소에서 파는 해금이 라이선스와 맞는지, 무료 코드 서명 자격(SignPath Foundation = OSI 라이선스, 비공개 구성요소 금지)과 충돌하는지가 쟁점
- Store MSIX는 Microsoft가 재서명하므로 서명비가 0원이다. 무료 서명 자격이 필요한 곳은 Store 밖(NSIS·winget)뿐

## Scores

| Axis | Result | Evidence |
|------|--------|----------|
| Feasibility | Pass | LICENSE 파일 추가만으로 기존 표기와 일치. Store 정책은 2022-07 오픈소스 판매 금지 문구를 철회 — OSI 앱을 Store에서 파는 것은 막히지 않음 |
| Direction fit | Pass | Store add-on 해금은 "편의·응원"을 파는 명예 제도로 설계(Krita·Files·Paint.NET Store판, NanaZip 후원 add-on 선례). 비공개 모듈을 두지 않으므로 SignPath 자격을 지킬 여지가 남음 |
| Efficiency | Pass | 빌드 한 벌·저장소 한 벌. 오픈 코어처럼 비공개 빌드를 따로 두지 않는다 |

## Alternatives considered

| Alternative | Pros | Cons | Better when |
|-------------|------|------|-------------|
| **MIT 확정 + 이름·아이콘 별도 (채택)** | 기존 표기와 일치, 무료 서명 자격 여지, 포크 동기 작음 | 누구나 해금을 지운 빌드를 만들 수 있음 | 해금이 편의·응원일 때 |
| Proprietary(EULA) | 재배포를 법으로 막음 | 이미 MIT로 적힌 버전과 충돌, 무료 서명 불가, 공개 소스라 우회는 여전 | 저장소를 비공개로 돌릴 때 |
| 오픈 코어(비공개 전용 테마·해금 모듈) | 전용 콘텐츠 보호 | SignPath "no proprietary component" 위반, 빌드 두 벌 | 전용 콘텐츠가 주 가치일 때 |
| 소스 공개형(PolyForm·FSL) | 상업 재배포 금지 | 비OSI → 무료 서명 불가, 기존 MIT와 충돌 | 처음부터 상업 앱일 때 |

## Decision

- Verdict: `ADOPT`
- What we will do now: 루트 `LICENSE`(MIT, Copyright (c) 2026 cyKim), `TRADEMARKS.md`(이름 "Frond"·앱 아이콘은 MIT 대상 아님, 한·영), README 라이선스 절 갱신
- What we will not do: 비공개 해금 모듈·비공개 전용 테마, EULA 전환, 저장소 비공개
- Modified approach: 구매자 전용 테마도 저장소에 공개한다(D9: Rust `include_str!` + 권리 확인 커맨드). 해금은 UI 경로에만 건다

## Follow-up

- [법률 확인] `TRADEMARKS.md`의 이름·아이콘 제외가 MIT 루트 LICENSE와 함께 유효한지(Joplin이 같은 구조 — 코드 AGPL, 로고 all rights reserved)
- [SignPath 문의] Store IAP 해금 코드와 `TRADEMARKS.md`가 든 OSI 프로젝트를 받는지 — Store 밖 서명을 시작할 때
- Certum Open Source 인증서는 "distributed commercially"에 쓰면 폐지 → Store 밖 서명 후보에서 뺀다
- Revisit when: 전용 콘텐츠를 보호해야 할 만큼 매출이 생기거나, 이름을 쓴 복제판이 Store에 올라올 때(11.2 지식재산 신고)
