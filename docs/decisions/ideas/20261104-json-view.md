## Context

- Goal of this pass: `.json` 계열 파일을 Frond 탭에서 JSON으로 연다. 범위(보기·편집·트리), 파서, 저장 의미, 큰 파일 경계, 출시 단위를 정한다
- Constraints:
  1. **지금도 `.json`은 열리지만 Markdown으로 렌더된다.**
     - argv·드래그·최근 파일·Markdown 링크로 열린다. `load_document`에 확장자 검사가 없다(`src-tauri/src/lib.rs:88-111`)
     - 종류 판정이 `isHtmlPath` 삼항이라 Markdown이 된다(`src/main.ts:289`)
     - 열기 대화상자(`main.ts:2030-2037`)와 폴더 트리(`src-tauri/src/tree.rs:19`)에는 보이지 않는다
  2. **문서 종류가 양자택일로 박혀 있다.**
     - `SourceLanguage = "markdown" | "html"`이다(`src/editor.ts:59`)
     - 다른 이름 저장 검사는 `isHtmlPath(target) !== (tab.kind === "html")`다(`main.ts:1367`). 세 번째 종류를 더하고 이 줄을 그대로 두면 JSON 탭을 `.md`로 저장할 수 있다
     - 확장자 목록이 10여 곳에 흩어져 있다: `main.ts:2030·2089·2119`, `src/render/links.ts:19-20`, `src/render/sanitize.ts:15-16`, `src/html-view.ts:27`, `tree.rs:19`, `integrations/open-new-md.ps1:67·91`
  3. **바이트 보존 원칙**: 무편집 저장은 원본 바이트를 그대로 쓴다(`crates/frond-core/src/document.rs:181-184`).
     - `JSON.parse→stringify`는 값을 바꾼다. 정수형 키가 재정렬되고, `é`→`é`, `1.0`→`1`, `-0`→`0`이 되고, 주석이 사라지고, 2^53을 넘는 정수는 반올림된다
     - jsonc-parser `format`은 공백만 고친다. 큰 수·`1.0`·`1e2`·`-0`·`é`·`\/`·짝 없는 서로게이트·주석·끝 쉼표가 그대로 남는다(실측)
  4. **서식 맞추기·저장에 함정이 둘 있다(실측).**
     - 한 줄 10MB 파일에 format 편집 81.8만 개를 CM6 `ChangeSet`으로 적용하면 힙 4GB·8GB 모두 메모리가 모자라 죽는다. 문서 전체를 한 번에 바꾸는 트랜잭션은 31ms다
     - 일부 줄만 다시 들여쓴 뒤 저장하면 줄바꿈 재대응 Myers 비교(`eol.rs:146-183`, deadline 없음)가 1MB 182ms, 10MB 11.7초 걸린다. `save_document`는 동기 명령이라 그동안 창이 멈춘다
     - 옛 줄바꿈이 한 가지뿐이면 `remap` 결과는 `vec![dominant; n]`과 같다. `carry`가 옛 줄바꿈만 옮기기 때문이다(코드로 확인)
  5. **파서별 특성**
     - CM6는 화면 + 10만 자까지만 파싱한다(`@codemirror/language` `Work.MaxParseAhead`). 50MB도 화면 근처는 32ms다
     - `@lezer/json` 문법에는 주석 토큰이 없다. JSONC 1MB에서 오류 노드 287개, JSONL 10MB를 한 번에 파싱하면 12,319개가 나온다
     - jsonc-parser `visit`은 50MB에 452ms, 순간 힙 약 1.7MB다. 같은 패키지의 `parseTree`는 50MB에 707MB를 쓴다
     - `JSON.parse`는 원문 위치를 주지 않고 큰 수를 반올림한다
  6. **크기 상한이 없다.**
     - 코어와 `load_document`에 상한이 없고, Rust 명령은 모두 동기다
     - 10MB Markdown 탭은 메모리 +550MB였다(`docs/roadmap.md:78`)
     - 트리를 다 그리면 1MB에 DOM 약 13만 개, 50MB를 모두 펼치면 2,013,314행이다
  7. **쓰임새**(디스크 파일과 AI Write 기록을 센 것이고, 연 기록은 아니다)
     - 보고서·QA JSON 459개: p50 1.8KB, p90 52KB, 최대 7.0MB. 같은 모양 객체 배열 33%, 2^53 초과 0, `\u` 이스케이프 1, BOM 2
     - Claude 세션 JSONL 2,812개: p90 5.2MB, p99 33.5MB, 최대 179.6MB
     - VS Code `settings.json`·`wrangler.jsonc`는 주석 때문에 엄격 파싱이 실패한다
  8. **AI 훅 후보**: 14일 동안 Claude가 Write한 JSON은 약 120개다.
     - 제외 폴더 밖은 65개이고, 상위는 `package.json`·`launch.json`·`settings.json`·`tsconfig.json`·`.mcp.json`이다
     - 문서 폴더 허용 목록을 통과한 것은 6개다
  9. **폴더 트리 소음**
     - 이 저장소에 추적 JSON이 12개, 생성물 `src-tauri/gen/schemas`가 4개다. Unity 프로젝트 `Library/` 아래에는 190개가 있다
     - 트리는 점 이름·숨김 속성·`node_modules`만 숨긴다(`tree.rs:20-55`)
  10. **번들**(esbuild, 앱 CM6 external)
      - `@codemirror/lang-json` 1.5KB, `@codemirror/lint` 6.1KB, jsonc-parser 쓰는 부분 4.2KB(모두 gzip)
      - 합계 +11.5KB gzip(+3.6%)이다. 지금 메인 번들에는 lint 코드가 없다
      - vanilla-jsoneditor는 앱 CM6를 빼도 183KB gzip이다
  11. **새 색 토큰이 필요 없다.**
      - 기존 토큰으로 충분하다: prettylights `constant`·`string`·`comment`, `fgColor-danger`·`fgColor-attention`·`fgColor-muted`(`src/theme/themes.ts`)
      - 문서 기능은 무료라는 원칙도 지킨다(`20261006-store-monetization.md:44`)
  12. **열린 일과 겹친다.**
      - next-session §2 N: HTML 실기

## Decision

- Verdict: 머리의 Verdict와 같다
- What we will do now (J-1~J-3, [구현 계획](#구현-계획)):
  1. **문서 종류를 `src/doc-kind.ts` 한 곳으로 모은다.**
     - 정의: `DocKind = "markdown" | "html" | "json"`, `docKind(path)`, `jsonVariant(path)` = `strict` | `jsonc` | `jsonl`
     - 확장자: `.json`·`.jsonc`·`.jsonl`·`.ndjson`. 모르는 확장자는 지금처럼 markdown이다
     - 알려진 JSONC 이름은 jsonc 변형으로 다룬다: `tsconfig*.json`, `jsconfig*.json`, `.vscode\*.json`, `devcontainer.json`, `.eslintrc.json`, `babel.config.json`, VS Code 사용자 `settings.json`·`keybindings.json`
     - 양자택일 조건과 흩어진 확장자 목록을 모두 이 모듈로 바꾼다
  2. **화면**: JSON 탭의 '보기'는 같은 CM6 편집기를 읽기 전용으로 띄운 화면이고, '소스'는 편집할 수 있는 같은 화면이다. 분할은 없다.
     - `tab.mode`는 그대로 `"view"`/`"source"`로 둔다. 상태바·세션·`openMode`와 어긋나지 않게 하려는 것이다
     - "편집기가 보인다"는 판정은 도우미 `editorShown(tab)` 하나로 모은다
  3. **소스 언어**
     - strict·jsonc: `@codemirror/lang-json`(문법 색, 접기 `foldGutter`·`foldKeymap`). `tags.invalid`는 칠하지 않는다
     - jsonl: lezer를 쓰지 않는 평문이다
     - 진단은 jsonc-parser `visit`으로 낸다
       - 오류는 offset과 함께 여러 개 낸다
       - strict 변형의 주석·끝 쉼표는 '표준 아님' 경고만 낸다
       - 중복 키를 경고한다
       - jsonl은 줄마다 검사한다
       - 진단은 200개까지만 보인다
     - `jsonParseLinter`는 쓰지 않는다
  4. **서식 맞추기·한 줄로**는 사용자가 누를 때만 실행한다.
     - jsonc-parser `format` 결과를 문자열로 만들어, 문서 전체를 한 번에 바꾸는 트랜잭션 하나로 넣는다
     - Ctrl+Z 한 번에 되돌아가고, `savedDoc` 비교로 dirty도 풀린다
  5. **저장 경로 보강**
     - 코어 `remap`은 옛 줄바꿈이 한 가지(또는 없음)면 diff 없이 바로 돌려준다. 결과는 같다
     - 줄바꿈이 없던 JSON에 줄바꿈이 생기면 저장 때마다 그 자리에서 판정해 `eol` 인자를 붙인다
  6. **크기 방어**(JSON만)
     - 열기 전에 크기를 본다. 20MB를 넘으면 확인 뒤 읽기 전용, 200MB를 넘으면 거절한다. 값은 WebView2 CDP 실측으로 확정한다
     - 2MB 넘는 JSON은 외부 변경 때 자동으로 다시 읽지 않고 배너로 알린다
  7. **폴더 트리**에 JSON을 '문서형만' 기본으로 보인다(설정 `treeJson`). §3-10 머지 뒤에 한다
- What we will not do:
  - 열기·저장 때 자동 서식. `JSON.parse→stringify`나 `serde_json::Value`로 쓰는 모든 경로
  - vanilla-jsoneditor·json-formatter-js·lossless-json·json5 도입, 자체 JSON 스캐너 작성
  - AI 훅으로 JSON 넘기기(별도 트랙 T-b)
    - 설정 파일·비밀이 노출되고 받은 목록에 소음이 생긴다
    - 허용 목록을 통과한 것은 14일에 6개뿐이다
  - `.json` 기본 앱 가져오기, `tauri.conf.json` `fileAssociations`에 `.json` 넣기. 넣으면 설치기 템플릿이 `HKCU\Software\Classes\.json` 기본값을 가져간다(`src-tauri/nsis/hooks.nsh` 머리 주석)

  - 원문 순서 typed array에 `kind`·`start`·`end`·`line`·`keyStart`·`size`·`parent`·`flags`를 담는다
  - 진단·목차·제목이 같은 색인을 쓴다
- 화면: `article` 직계에 평평한 행을 두고 `data-line`을 단다. 그래서 `viewLineRange`·`scrollViewToLine`·`syncMapFor`·인쇄가 그대로 돈다.
  - 자식은 펼칠 때 만든다. 배열은 100개씩 묶고, 문자열은 250자에서 자른다
  - 처음 펼침은 100KB 이하면 7단계(Firefox), 그 위면 2단계다. 모두 펼치기는 10만 노드까지다
- 배지·복사: 큰 수, 중복 키(가려짐), JS 경로·JSON Pointer(RFC 6901 `~0`/`~1`) 복사를 오른쪽 클릭 메뉴에 넣는다
- 보안
  - 키·값·툴팁은 textContent로만 넣는다
  - 제어 문자·양방향 제어·폭 없는 글자는 이스케이프로 보인다
  - 링크는 `^https?://`이면서 `URL.canParse`를 통과한 것만, Ctrl+클릭으로만 연다
- 찾기·목차
  - `find.ts`에 `reveal` 훅을 두고, 디코드한 텍스트를 기준으로 찾는다
  - 목차는 최상위 키를 level 2로 낸다
- 모듈은 첫 JSON 탭에서 지연 import한다(`export-html.ts` 선례). 설정은 `jsonExpand`(보기 탭, 기본 `auto`)다
- 가상 목록·Worker는 CDP 실측에서 필요할 때만 들인다
