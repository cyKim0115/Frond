Constraints (must hold for every variant):

- Pillars: 깔끔함 · 신뢰(바이트 보존·데이터 무손실) · 즉시성
- Scope: 단일 사용자 Windows 데스크톱 편집기. 노트 앱(볼트·백링크·동기화) 아님
- Tech / content limits: Tauri 2 + CM6 + markdown-it. 새 렌더(Mermaid·KaTeX)는 지연 로드로 첫 렌더 시간을 늘리지 않는다
- Do not touch: `samples/raw/` 픽스처, 설치본 사용자 설정(localStorage) 형식 — 바꾸면 이전 값을 읽어 옮긴다
