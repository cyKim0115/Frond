## 2. 사용자가 할 일 ★ 내일 실기 테스트

먼저 새 설치기 `target\release\bundle\nsis\MdEditor_0.1.0_x64-setup.exe`를 실행해 **추가/재설치**를 끝까지 진행(또는 `/S`). 같은 버전이라 설치기가 유지 관리 페이지를 먼저 띄운다 — 창을 닫으면 아무것도 바뀌지 않는다.
**`samples/raw/`는 바이트 픽스처라 직접 편집·저장하지 말고 복사본으로 시험한다.**

### A. 1-7 재확인 (어제 남은 것)

1. `samples/paths/paths.md` → 64 px 단색 정사각형(빨강·초록·파랑·주황)이 위 두 절에 4개씩, "인코딩 없이" 절에 2개 = **10개**. 마지막 `![한글 raw](…)` 줄은 글자 그대로
2. `samples/large/10mb.md` 열기 ≤ 5 s. 연 뒤 탐색 영역(`Ctrl+Shift+E`)·목차(`Ctrl+\`)·줌·스크롤이 긴 멈춤 없이 반응. 2 MB 초과 문서는 패널 애니메이션이 없는 게 정상. `Ctrl+P` 미리보기에 끝까지
3. 관리자 경고: 시작 메뉴 MdEditor 우클릭 → 관리자 권한으로 실행 → 상태바 빨간 "관리자 권한 실행 중"(툴팁에 이유). 일반 실행에서는 없어야 한다
4. 최근 파일 제목: 첫 줄 문서 제목, 둘째 줄 파일 이름·폴더. 제목 없는 문서는 파일 이름·폴더

### B. Phase 2 편집·저장

1. `Ctrl+/` 보기 ↔ 소스: 보던 위치가 이어지는지, 소스로 들어가면 커서가 보던 줄에 있는지. 상태바 '보기/소스' 클릭으로도
2. **한글 IME**: 소스 모드에서 한글 입력, 조합 중 `Ctrl+S`·버튼 클릭·Alt+Tab, 자동 줄바꿈 경계 입력, 선택 후 Backspace → 글자 유실·중복 없음 (Phase 0 시나리오 ①–⑦)
3. 저장 바이트 보존: `samples/raw/utf8-crlf.md`·`mixed-eol.md`·`utf8-bom.md` **복사본**을 열어 한 줄만 고치고 `Ctrl+S` → 비교 도구로 그 줄만 바뀌었는지(줄바꿈·BOM 그대로)
4. 충돌: 편집 중에 다른 편집기로 같은 파일을 저장 → 경고 배너 → `Ctrl+S` → 충돌 팝업(다른 이름으로·덮어쓰기·취소)
5. EUC-KR: `samples/raw/cp949.md` 복사본에 이모지 넣고 저장 → "표현할 수 없는 문자" 팝업, 상태바 인코딩 메뉴(다시 열기·변환)
6. 초안: 편집 후 60초 넘게 두고 작업 관리자로 MdEditor 강제 종료 → 같은 파일 다시 열기 → 복구 팝업
7. 닫기 확인: 저장 안 한 채 X·`Alt+F4` → 저장/저장 안 함/취소
8. 찾기: 보기 `Ctrl+F`(Enter·Shift+Enter·Esc), 소스 `Ctrl+F`/`Ctrl+H` 바꾸기·모두 바꾸기
9. 이미지: 화면 캡처 후 소스 모드에서 `Ctrl+V` → 문서 옆 `assets/`에 PNG·링크. 이미지 파일을 소스 모드에 끌어다 놓기
10. `Ctrl+Shift+S` 다른 이름으로 저장 → 새 파일로 전환, 원래 인코딩·줄바꿈 유지

### C. 셸 트랙 (설정·테마)

1. `Ctrl+,` → 왼쪽 탭 5개(보기·편집·테마·탐색·파일), ↑↓로 탭 이동, 마지막 탭 기억, 값 바로 적용·↺·모두 기본값으로
2. 테마: '시스템 설정 따르기' + Windows 라이트/다크 전환 → 라이트/다크 테마 쌍 적용. `Ctrl+Shift+D`로 쌍 전환
3. 전환 연출: 색이 250 ms 동안 부드럽게 바뀌는지(전환 시간 0이면 즉시). 10 MB 문서에서는 화면 전체 크로스페이드
4. 테마 가져오기: 설정 테마 탭 → 가져오기… → `docs/themes/sepia.json` → 목록에 세피아 → 적용. 복제 → 폴더 열기에서 복제본 색 바꾸기 → 다시 읽기. 내보내기, 삭제(쓰던 테마면 라이트로)
5. 잘못된 테마 파일(예: 값 하나를 `"url(x)"`로) 가져오기 → 어느 키·값인지 알려 주고 저장 안 함. 재시작 후에도 가져온 테마·선택 유지

### D. 확인이 필요한 결정

- **사용자 테마 파일 형식** — 색 토큰 JSON(`id`·`name`·`base`·`shell`·`doc`), 확장자 `.json`, 토큰 전부 공개(README "테마 파일"). 에이전트 권장안으로 구현했다: [`decisions/ideas/20260930-theme-file-format.md`](decisions/ideas/20260930-theme-file-format.md). 괜찮으면 기록의 Status를 확정으로
- **푸시**: 2026-09-30 야간 커밋은 로컬에만 있다

결과를 알려 주면 에이전트가 `fidelity-report.md`(readonly QA 형식)를 쓰고 1-7·Phase 2·셸 트랙을 닫는다. 그 뒤 MVP 완료 → RAG 캡처 검토(§4).
