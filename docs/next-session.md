### B. Phase 2 편집·저장

1. `Ctrl+/` 보기 ↔ 소스: 보던 위치가 이어지는지. 상태바 '보기/소스' 클릭으로도. 소스 → 보기 → 소스로 바로 돌아오면 **커서·선택이 그대로**인지, 보기에서 조금 내렸다 와도 커서가 남는지, 멀리 이동했다 오면 보던 줄로 가는지
2. **한글 IME**: 소스 모드에서 한글 입력, 조합 중 `Ctrl+S`·버튼 클릭·Alt+Tab, 자동 줄바꿈 경계 입력, 선택 후 Backspace → 글자 유실·중복 없음 (Phase 0 시나리오 ①–⑦)
3. 저장 바이트 보존: `samples/raw/utf8-crlf.md`·`mixed-eol.md`·`utf8-bom.md` **복사본**을 열어 한 줄만 고치고 `Ctrl+S` → 비교 도구로 그 줄만 바뀌었는지(줄바꿈·BOM 그대로)
4. 충돌: 편집 중에 다른 편집기로 같은 파일을 저장 → 경고 배너 → `Ctrl+S` → 충돌 팝업(다른 이름으로·덮어쓰기·취소)
5. EUC-KR: `samples/raw/cp949.md` 복사본에 이모지 넣고 저장 → "표현할 수 없는 문자" 팝업, 상태바 인코딩 메뉴(다시 열기·변환)
6. 초안: 편집 후 60초 넘게 두고 작업 관리자로 MdEditor 강제 종료 → 같은 파일 다시 열기 → 복구 팝업
7. 닫기 확인: 저장 안 한 채 X·`Alt+F4` → 저장/저장 안 함/취소
8. 찾기: 보기 `Ctrl+F`(Enter·Shift+Enter·Esc), 소스 `Ctrl+F`/`Ctrl+H` 바꾸기·모두 바꾸기
9. 이미지: 화면 캡처 후 소스 모드에서 `Ctrl+V` → 문서 옆 `assets/`에 PNG·링크. 이미지 파일을 소스 모드에 끌어다 놓기
10. `Ctrl+Shift+S` 다른 이름으로 저장 → 새 파일로 전환, 원래 인코딩·줄바꿈 유지

### C. 셸 트랙 (설정·테마)

1. `Ctrl+,` → 왼쪽 탭 5개(보기·편집·테마·탐색·파일), ↑↓로 탭 이동, 마지막 탭 기억, 값 바로 적용·↺·모두 기본값으로
2. 테마: '시스템 설정 따르기' + Windows 라이트/다크 전환 → 라이트/다크 테마 쌍 적용. `Ctrl+Shift+D`로 쌍 전환
3. 전환 연출: 색이 250 ms 동안 부드럽게 바뀌는지(전환 시간 0이면 즉시). 10 MB 문서에서는 화면 전체 크로스페이드
4. 테마 가져오기: 설정 테마 탭 → 가져오기… → `docs/themes/sepia.json` → 목록에 세피아 → 적용. 복제 → 폴더 열기에서 복제본 색 바꾸기 → 다시 읽기. 내보내기, 삭제(쓰던 테마면 라이트로)
5. 잘못된 테마 파일(예: 값 하나를 `"url(x)"`로) 가져오기 → 어느 키·값인지 알려 주고 저장 안 함. 재시작 후에도 가져온 테마·선택 유지
6. **추천 테마**: 테마 탭 '추천 테마…' → 몇 개 '적용'해 보며 색이 마음에 드는지(팔레트 테마는 연한 강조색을 읽히게 진하게 바꿔 쓴다) → '모두 추가' → 폴더 열기에 `wedding-*.json`이 생겼는지 → 재시작 후에도 목록에 있는지. 이미 가져온 세피아는 '추가됨'
7. 제목 표시줄: 맨 위 띠의 파일 이름 위에서 커서가 화살표이고 드래그해도 글자가 선택되지 않는지. 띠 드래그로 창 이동·두 번 클릭 최대화는 그대로
