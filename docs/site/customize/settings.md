# 설정

`Ctrl+,` 또는 제목 표시줄의 톱니 버튼으로 엽니다. 왼쪽 탭을 고르면 그 분류의 항목만 보입니다. 바꾼 값은 바로 적용되고 저장됩니다. 기본값과 다른 항목 옆의 ↺ 버튼으로 하나씩, **모두 기본값으로**로 한꺼번에 되돌립니다.

## 업데이트

설치기로 설치한 Frond는 새 버전을 조용히 받아 두고, 다 받으면 제목 표시줄 오른쪽에 **업데이트**를 띄웁니다. 누르면 바뀐 점을 보여 주고 고르게 합니다.

- **재시작해 업데이트** — 저장하지 않은 문서가 있으면 '모두 저장하고 업데이트'나 '초안으로 두고 업데이트'를 고릅니다. 다시 열리면 열어 둔 탭·모드·보던 위치가 그대로 돌아오고('시작할 때'가 빈 창이어도 이번 한 번은), 초안으로 둔 문서는 열 때 복구를 묻습니다
- **나중에** — 이번 실행 동안 버튼을 흐리게 둡니다. 같은 버전을 7일 넘게 미루면 버튼이 진해집니다
- **이 버전 건너뛰기** — 그 버전은 다시 알리지 않고, 더 새 버전이 나오면 알립니다. 설정 '업데이트' 탭의 '다시 알리기'로 되돌립니다

설치하는 동안 작은 진행 창이 뜨고 Frond가 다시 열립니다. 관리자 권한은 필요 없습니다. Microsoft Store판은 Store가, Scoop판은 `scoop update frond`가 업데이트합니다. 무엇을 보내는지는 [개인정보처리방침](../privacy.md)에 있습니다.
