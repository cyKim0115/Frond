# 지원하는 Markdown

GitHub 스타일(표·체크리스트·각주·front matter·코드 구문 강조)로 그립니다. 아래는 그 밖의 확장입니다.

## Mermaid 다이어그램

` ```mermaid ` 코드 블록은 다이어그램으로 그립니다. 순서도·시퀀스·파이·간트·클래스·상태 등을 지원하고, 마인드맵·아키텍처 다이어그램은 지원하지 않습니다.

- 라이브러리는 문서에 Mermaid가 있을 때만 불러옵니다
- 라벨의 HTML·클릭 동작은 막습니다(`securityLevel: strict`)
- 라이트·다크 테마를 따라 다시 그립니다
- 문법이 틀리면 코드 블록 아래에 이유를 보여 줍니다

## GitHub Alerts

인용의 첫 줄이 `[!NOTE]`·`[!TIP]`·`[!IMPORTANT]`·`[!WARNING]`·`[!CAUTION]`이면 GitHub처럼 색 틀·아이콘이 붙은 알림 상자로 그립니다.

```markdown
> [!NOTE]
> 알림 내용입니다.
```

그 줄에 다른 글자가 있거나 목록 안에 있으면 보통 인용으로 그립니다.

## 수식

`$E=mc^2$`처럼 `$`로 감싸면 인라인, `$$` 줄 사이나 ` ```math ` 블록은 가운데 정렬 수식입니다(KaTeX).

- `$5와 $10`, `$ x$`(안쪽 공백)는 GitHub처럼 글자 그대로입니다. `\$`는 달러 기호입니다
- 수식이 있을 때만 KaTeX를 불러옵니다
- 틀린 수식은 빨간 원문으로 남깁니다

## 원문 HTML

문서 안의 HTML 태그는 허용 목록만 그립니다: `<details>`·`<summary>`·`<img>`·`<br>`·`<kbd>`·`<sub>`·`<sup>`·`<mark>`·표 태그 등. 속성도 `width`·`align`·`href`·`src` 같은 목록만 남깁니다.

목록 밖 태그(`<script>`, 산문 속 `List<String>` 등)는 글자 그대로 보이고, 주석 `<!-- -->`은 숨깁니다.

## 자동 링크

`https://`처럼 스킴이 있는 주소와 `www.`로 시작하는 주소가 자동 링크가 됩니다. `paths.md`·`example.com`처럼 둘 다 없는 것은 글자 그대로입니다.

## 큰 문서

2 MB가 넘는 문서는 **큰 문서 모드**입니다. 코드 구문 강조와 패널 열고 닫기 애니메이션을 생략하고, 화면 밖 블록은 100개 묶음 단위로 건너뛰었다가 스크롤해 올 때 그립니다. 10 MB 문서도 열립니다.
