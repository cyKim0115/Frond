# 알아 둘 점·문제 해결

## 탐색기 더블클릭이 안 먹어요

관리자 권한으로 실행한 Frond 창에는 탐색기 더블클릭이 전달되지 않습니다(Windows UIPI). 상태바에 빨간 **관리자 권한 실행 중** 경고가 뜨면 앱을 일반 권한으로 다시 실행하거나 `Ctrl+O`·끌어다 놓기로 여세요.

## 글자가 깨져 보여요

상태바 인코딩을 눌러 **다시 열기**에서 맞는 인코딩(UTF-8 / EUC-KR / UTF-16LE)을 고릅니다. 해석 못 한 바이트가 있는 문서는 읽기 전용이라 먼저 맞는 인코딩으로 열어야 편집됩니다. [인코딩과 줄바꿈](../write/encoding-and-eol.md)을 봅니다.

## 문서 안 HTML이 글자 그대로 보여요

허용 목록 밖 태그는 글자 그대로 보입니다. [지원하는 Markdown](../read/markdown.md#원문-html)을 봅니다.

## 큰 문서가 느려요

2 MB가 넘으면 **큰 문서 모드**로 구문 강조와 일부 애니메이션을 생략합니다. 1 MB 이상 문서의 인쇄 미리보기는 오래 걸릴 수 있습니다.

## 저장하지 않고 종료됐어요

같은 파일을 다시 열면 **복구 / 초안 버리기**를 묻습니다. [외부 변경과 초안 복구](../write/external-changes.md#초안-백업과-복구)를 봅니다.

## AI 훅이 새 문서를 못 넘겨요

[AI 앱 연동](../more/ai-integration.md)의 설치 절을 확인하고, 훅 판단 기록 `%TEMP%\mdeditor-open-hook.log`를 봅니다.
