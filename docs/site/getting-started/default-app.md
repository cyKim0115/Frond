# `.md` 기본 앱으로 지정

두 가지 방법이 있습니다.

## 탐색기에서

1. 탐색기에서 `.md` 파일을 오른쪽 클릭 → **연결 프로그램** → **다른 앱 선택**
2. **Frond**를 고릅니다
3. **항상 이 앱을 사용하여 .md 파일 열기**를 체크합니다

## 앱 상태바에서

상태바의 **기본 앱으로 설정** 버튼을 누르면 Windows 기본 앱 설정이 열립니다. 거기서 Frond를 고릅니다. 이 버튼은 Frond가 기본 앱이 아닐 때만 보입니다.

> [!NOTE]
> 관리자 권한으로 실행한 Frond 창에는 탐색기 더블클릭이 전달되지 않습니다. 자세한 내용은 [알아 둘 점·문제 해결](../reference/troubleshooting.md)을 봅니다.
