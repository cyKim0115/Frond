# 다른 프로그램이 파일을 바꿀 때

## 자동 반영

연 파일을 다른 편집기에서 저장하면 몇 초 안에 다시 읽고 스크롤 위치를 유지합니다(뒤 탭도). 파일이 지워지거나 옮겨지면 본문 위에 배너가 뜨고 마지막 내용을 계속 보여 줍니다. `F5`로 직접 다시 읽을 수도 있습니다(편집 중이면 변경을 버릴지 묻습니다).

## 편집 중인데 바뀌었을 때

저장하지 않은 편집이 있을 때 파일이 바뀌면 배너로 **비교 / 다시 읽기(내 변경 버림) / 내 변경 유지**를 고릅니다.

## 비교

편집기 안에 디스크 내용(빨강)과 편집 중 내용(초록)의 차이가 보입니다.

1. 부분마다 **내 것 유지 / 디스크 것으로**를 고릅니다
2. 다 고르면 저절로 끝납니다
3. 비교한 뒤 저장하면 충돌을 다시 묻지 않고 편집기 내용으로 씁니다

## 초안 백업과 복구

저장하지 않은 편집을 설정한 간격(기본 60초)마다 `%APPDATA%\Frond\drafts`에 남깁니다. 강제 종료·정전 뒤 같은 파일을 열면 **복구 / 초안 버리기**를 묻습니다. 저장하거나 변경을 버리면 초안은 지워집니다. 간격은 설정 **파일** 탭의 **초안 백업 간격**이고 0이면 끕니다.
