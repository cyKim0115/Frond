# 인코딩과 줄바꿈

Frond는 UTF-8·CP949(EUC-KR)를 자동으로 판별합니다.

## 인코딩

상태바의 인코딩을 누르면 메뉴가 열립니다.

| 항목 | 하는 일 |
|---|---|
| **다시 열기** (UTF-8 / EUC-KR / UTF-16LE) | 파일은 그대로 두고 글자 해석만 바꿉니다. 글자가 깨져 보일 때 씁니다 |
| **변환해 저장** (UTF-8 / UTF-8 BOM) | 파일을 새 인코딩으로 바로 저장합니다. 파일 바이트가 바뀝니다 |

### 표현할 수 없는 문자

EUC-KR 파일에 이모지처럼 그 인코딩에 없는 문자를 넣고 저장하면 몇 행 몇 열인지 알려 주고 **UTF-8로 변환해 저장**을 제안합니다.

## 줄바꿈

상태바의 줄바꿈(`LF` / `CRLF`, 섞여 있으면 `(혼합)`)을 누르면 **LF로 변환해 저장 / CRLF로 변환해 저장**을 고릅니다. 모든 줄의 줄바꿈을 하나로 맞춰 바로 저장합니다.

평소 저장은 줄마다 원래 줄바꿈을 지킵니다. 변환은 고른 그 저장 한 번만 합니다.
