# 내보내기와 인쇄

제목 표시줄 설정 옆 **⋯(문서 메뉴)**에 파일 열기 · 폴더 열기 · **HTML로 내보내기…** · **인쇄 · PDF로 저장…** · 설정이 있습니다.

## HTML로 내보내기

지금 화면 그대로(테마 색·본문 폭·코드 강조·Mermaid 그림·수식) HTML 파일 하나로 저장합니다. 탭 오른쪽 클릭으로도 할 수 있습니다. 이미지는 두 가지 중 고릅니다.

| 선택 | 특징 |
|---|---|
| **파일 안에 넣기** | 한 파일로 주고받기 좋음 |
| **경로로 두기** | 가볍지만 이미지 파일이 함께 있어야 함 |

## 인쇄·PDF

`Ctrl+P` 또는 오른쪽 클릭 메뉴의 **인쇄**.

- 제목 표시줄·목차·상태바를 빼고 본문만 찍고, 아래에 쪽 번호가 붙습니다. 긴 코드 줄은 접힙니다
- 소스·분할 모드에서도 고친 내용으로 찍습니다
- 다크 테마여도 라이트로 찍습니다(그림 포함)
- PDF 저장은 인쇄 대화상자에서 'Microsoft Print to PDF'·'PDF로 저장'을 고릅니다. PDF 파일 이름은 문서 이름입니다
- 1 MB 이상인 문서는 인쇄 미리보기가 오래 멈출 수 있어 먼저 **계속 / 취소**를 묻습니다
