# MdEditor

Markdown(`.md`) 파일을 보고 편집하는 개인용 Windows 데스크톱 앱입니다. Tauri 2 기반이라 설치기가 작고(약 4 MB) 빨리 뜹니다.

![MdEditor 기본 화면 — 왼쪽 목차, 오른쪽 본문](docs/screenshots/main.png)

> **현재 단계: 뷰어.** 문서를 열어 읽는 기능까지 구현돼 있습니다. 설치기·파일 연결은 실기 검증 중이고, 편집·저장은 다음 단계(Phase 2)입니다.
> 진행 상황은 [docs/next-session.md](docs/next-session.md), 전체 계획은 [docs/roadmap.md](docs/roadmap.md)에 있습니다.

## 주요 기능

- `.md` 더블클릭 → 바로 렌더. 이미 떠 있으면 새 창을 띄우지 않고 같은 창에서 엽니다
- GitHub 스타일 렌더: 표·체크리스트·각주·front matter·코드 구문 강조
- 한국어 타이포그래피: 단어 중간에서 줄이 끊기지 않고, 코드는 D2Coding 글꼴
- 경계 없는 제목 표시줄, 열고 닫는 탐색 영역(최근 파일), 폭을 바꾸는 목차
- 다른 편집기에서 저장하면 자동으로 다시 읽기(스크롤 위치 유지)
- 라이트/다크 모드, 줌, 인쇄
- UTF-8·CP949(EUC-KR) 자동 판별, BOM·줄바꿈(LF/CRLF/혼합) 표시. 파일 바이트는 건드리지 않습니다

## 설치

준비물: [Node.js](https://nodejs.org/) 20 이상, [Rust](https://rustup.rs/)(stable, MSVC), Windows 10/11.

```powershell
npm install
npm run app:build
```

`target\release\bundle\nsis\MdEditor_0.1.0_x64-setup.exe`가 만들어집니다. 실행하면 현재 사용자 계정에 설치됩니다(관리자 권한 불필요, `%LOCALAPPDATA%\MdEditor`). WebView2 런타임이 없으면 설치기가 내려받습니다.

### `.md` 기본 앱으로 지정

- 탐색기에서 `.md` 파일 우클릭 → **연결 프로그램** → **다른 앱 선택** → **MdEditor**를 고르고 **항상 이 앱을 사용하여 .md 파일 열기**를 체크
- 또는 앱 상태바의 **기본 앱으로 설정** 버튼(현재 기본 앱이 아닐 때만 보임) → Windows 기본 앱 설정에서 MdEditor 선택

## 사용법

### 파일 열기

| 방법 | 설명 |
|---|---|
| 탐색기에서 더블클릭 | 기본 앱으로 지정했거나 **연결 프로그램**으로 열 때 |
| 창에 끌어다 놓기 | 파일을 창 아무 곳에나 놓으면 됩니다 |
| `Ctrl+O` | 파일 열기 대화상자 (`.md`·`.markdown`·`.txt` 등) |
| 최근 파일 | 왼쪽 탐색 영역의 목록에서 클릭 |
| 문서 안 링크 | 다른 `.md`로 가는 로컬 링크는 앱 안에서 열립니다. `http(s)`·`mailto` 링크는 기본 브라우저로 열립니다 |

### 화면 구성

![탐색 영역을 연 화면 — 최근 파일, 목차, 본문](docs/screenshots/recent-files.png)

| 영역 | 설명 |
|---|---|
| **제목 표시줄** (맨 위) | 빈 곳을 끌면 창 이동(화면 끝에 붙이기 가능), 두 번 클릭하면 최대화/복원. 창 가장자리를 끌어 크기를 바꿉니다. 왼쪽 끝은 탐색 영역 토글, 오른쪽은 설정·최소화·최대화·닫기 |
| **탐색 영역** (왼쪽) | 위쪽 정사각형 탭으로 패널을 고릅니다. 지금은 **최근 파일** 탭 하나 |
| **목차** | 문서의 제목 목록. 클릭하면 그 제목으로 이동하고, 스크롤하면 지금 읽는 제목이 파랗게 표시됩니다 |
| **본문** | 렌더된 문서. 폭은 설정의 **본문 최대 폭**을 따릅니다 |
| **상태바** (맨 아래) | 파일 경로 · 인코딩(해석 못 한 바이트가 있으면 빨간색) · 줄바꿈 · 줌 비율 |

### 탐색 영역과 최근 파일

- 제목 표시줄 왼쪽 끝 버튼이나 `Ctrl+Shift+E`로 열고 닫습니다. 열림 상태는 다음 실행 때도 유지됩니다
- 문서를 열 때마다 목록 맨 위에 올라가고, 지금 연 파일은 파란색으로 표시됩니다
- 항목에 마우스를 올리면 나오는 **×** 로 하나씩, 휴지통 버튼으로 전체를 지웁니다(한 번 더 확인). 목록에서만 빠지고 파일은 지워지지 않습니다
- 지워지거나 옮겨진 파일을 누르면 알림을 띄우고 목록에서 뺍니다

![지워진 파일을 눌렀을 때의 알림](docs/screenshots/missing-file.png)

### 목차

- 제목을 누르면 그 제목으로 이동합니다. 제목 위에 남는 간격은 설정의 **제목 이동 시 위쪽 여백**으로 바꿉니다
- 목차 오른쪽 경계를 끌어 폭을 바꿉니다(최소 160 px, 최대는 남은 폭의 절반). 경계를 두 번 누르면 기본 폭(260 px), 경계에 포커스를 두고 `←`/`→`로도 조절됩니다
- 아주 좁게(80 px 아래로) 끌면 목차가 접힙니다. `Ctrl+\`로 다시 엽니다
- 제목이 없는 문서, 창 폭이 720 px 이하일 때는 목차가 숨겨집니다

### 설정

`Ctrl+,` 또는 제목 표시줄의 톱니 버튼으로 엽니다. 바꾼 값은 바로 적용되고 저장됩니다. 기본값과 다른 항목 옆의 ↺ 버튼으로 하나씩, **모두 기본값으로**로 한꺼번에 되돌립니다.

![설정 팝업](docs/screenshots/settings.png)

| 항목 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| 테마 | 시스템 설정 따르기 | 시스템 / 라이트 / 다크 | `Ctrl+Shift+D`로 바꿔도 여기에 저장됩니다 |
| 본문 최대 폭 | 860 px | 480–1920 px | 창이 넓어도 본문 줄 길이를 이 폭으로 제한 |
| 제목 이동 시 위쪽 여백 | 24 px | 0–240 px | 목차·문서 안 링크로 제목에 이동할 때 제목 위에 남길 간격 |
| 최근 파일 개수 | 20개 | 1–100개 | 탐색 영역에 보일 최근 파일 수 |

### 다크 모드

기본은 Windows 설정을 따릅니다. `Ctrl+Shift+D`나 설정의 **테마**로 바꿉니다.

![다크 모드 — 코드 구문 강조](docs/screenshots/dark.png)

### 그 밖에

- **외부 변경 자동 반영**: 연 파일을 다른 편집기에서 저장하면 몇 초 안에 다시 읽고 스크롤 위치를 유지합니다. 파일이 지워지거나 옮겨지면 본문 위에 배너가 뜨고 마지막 내용을 계속 보여 줍니다
- **다시 읽기**: `F5`
- **줌**: `Ctrl+=` / `Ctrl+-` / `Ctrl+0` (50–300 %). 본문만 커지고 목차·메뉴는 그대로입니다
- **인쇄**: `Ctrl+P`. 제목 표시줄·목차·상태바를 빼고 본문만 인쇄하며, 긴 코드 줄은 접힙니다. PDF 저장은 인쇄 대화상자에서 고릅니다

### 알아 둘 점

- 문서 안의 HTML 태그(`<details>`, `<img>` 등)는 실행하지 않고 글자 그대로 보여 줍니다(안전 우선, GitHub과 다름)
- `https://`처럼 스킴이 있는 주소만 자동 링크가 됩니다. `www.example.com`은 링크가 되지 않습니다

## 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl+O` | 파일 열기 |
| `Ctrl+Shift+E` | 탐색 영역 열기/닫기 |
| `Ctrl+\` | 목차 보이기/숨기기 |
| `Ctrl+,` | 설정 |
| `Ctrl+Shift+D` | 라이트/다크 전환 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 확대 / 축소 / 원래 크기 |
| `F5` | 다시 읽기 |
| `Ctrl+P` | 인쇄 |
| `Esc` | 팝업 닫기 |

## 개발

```powershell
npm install                       # 처음 한 번
npm run app:dev -- -- 파일.md      # Tauri 개발 실행 (인수로 연 파일 경로 테스트)
npm run dev                       # 브라우저 미리보기 http://localhost:1422/?sample=samples/showcase.md
npm test                          # vitest (렌더 파이프라인·최근 파일·설정·목차 폭)
npx tsc --noEmit                  # 타입 검사
cargo test                        # Rust 코어·백엔드 단위 테스트
npm run app:build                 # 릴리스 + NSIS 설치기
```

- 스택: Tauri 2 · Vite · TypeScript(프레임워크 없음) · markdown-it · highlight.js · DOMPurify. 파일 읽기는 Rust 크레이트 [`crates/mdeditor-core`](crates/mdeditor-core)가 맡습니다
- 폴더 구조·작업 규칙은 [CLAUDE.md](CLAUDE.md), 결정 기록은 [docs/decisions/](docs/decisions/)에 있습니다
- 설정 항목은 `src/settings.ts`의 `SETTINGS`에 하나 더하면 설정 팝업에 자동으로 나타납니다
- `docs/screenshots/`의 화면은 실제 앱(1200 × 760)에서 찍었습니다
